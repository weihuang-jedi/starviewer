How To Run NV on Geyser

How to Run on Geyser:


  1. add /glade/apps/contrib/nv/bin to your path
  2. add /glade/apps/contrib/nv/lib to your LD_LIBRARY_PATH
  3. set /glade/apps/contrib/nv/data as environment variable NV_DATA
  4. have NCARG_ROOT setup properly, so NV can find NCL color table. example NCARG_ROOT: /glade/apps/opt/ncl/6.2.0/gnu/4.7.2
  5. follow instructions from CISL web site on how to do visualization on geyser to setup
  6. run "nv4se your-se-data" for CAM-SE data
  7. run "nv4fv your-fv-data" for CAM-FV data

A C-shell scrip to setup nv environment: 

 setenv PATH "/glade/apps/contrib/nv/bin:${PATH}"
 setenv NV_DATA /glade/apps/contrib/nv/data
 setenv LD_LIBRARY_PATH "/glade/apps/contrib/nv/lib:${LD_LIBRARY_PATH}"

Below are step by step of running nv on geyser on Mac.

(Linux users should have something similar. Please refer to CISL web site on how to do visualization on geyser)

  1. If you logged on to yellowstone, submit a batch job first:

    bsub -Is -q geyser -W 6:00 -n 1 -P YOUR_PROJECT_NUMBER_START_WITH_P tcsh

    Which will log you on to geyser.

  2. on geyser, run:

    /opt/TurboVNC/bin/vncserver -geometry 1600x1200

    You will get something like:

    New 'X' desktop is geyserXX:Y

  3. Back to you local system, run:

    vncviewer geyserXX.ucar.edu:Y

    Here XX, and Y must match the one you get from geyser.


    Fellow the instruction to log on to geyser again. But, this time, you are connectted through virtual GL channel, which allow you to run OpenGL through turboVNC.


    nv4se, nv4fv are scripts, which have already invoked vglrun, and customrized to cam-se, or cam-fv.

  4. Now a new window will pop up. In the new window:


    press and hold on "Applications", and move to "System Tools", and then choose "Terminal".


    This will give you a new terminal (in the new window).


    The font may be too small. If that is the case, then hold on "control" and "shift", and press "+" key to increase the font size.

  5. Go to your working directory.


    Run nv4se, or nv4fv in this new terminal ONLY.

  6. Hope everything worked for you.
