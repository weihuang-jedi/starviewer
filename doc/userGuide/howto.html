How to Navigate in NV

Select Color Map:


  1. Move mouse (cursor) to left box of "ColorMapNames" section.
  2. Mouse down to see the color map names
  3. Select a color map


Select Variable:


  1. Move mouse (cursor) to "Variables" section.
  2. Select 2D variables from left drowdown box
  3. Select 3D variables from right drowdown box


Choose what to Plot:


  • View images from NCL or from OpenGL
    1. The default is show images generated by NCL.
    2. Unselect NCL button to view images from OpenGL.
  • Select the section(s)/plane(s) in Cross-Section box
    1. Slide x slider to view an Y-Z plane plot.
    2. Slide y slider to view an X-Z plane plot.
    3. Slide z slider to view an X-Y plane plot.
    4. Click X2, Y2, Z2 to have a second cross-section.


Save an Image:


  1. Click SaveIamge button to save an image
  2. The image is named test.bmp. Use preview or other tools to convert it to other format.
  3. Use "Grab" on Mac to get a screen shot.
